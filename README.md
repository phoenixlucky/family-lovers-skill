## 📖 这是什么

**家庭关怀技能**是一个为**原生家庭觉察与疗愈**设计的 AI 陪伴 Skill。

它不追求给出标准答案——而是让你**在被理解的感觉中，重新看见自己**。

> 不是心理医生，不是人生导师。  
> 是一个足够温暖、足够安全的陪伴者。  
> 让你在对话中，慢慢理清那些来自家庭的"应该"和"不可以"里，  
> 哪些可以放下，哪些可以重新选择。

## 🔍 常见原生家庭模式

| 模式 | 典型表现 | 可能的成年后影响 |

## 🧠 路由引擎

Skill 内置一个智能对话路由引擎（`src/router.js`），能自动判断用户意图并匹配最合适的身份：

1. **检测输入** — 分析文本关键词和情感强度
2. **打分排序** — 危机 > 疗愈 > 觉察 > 行动 > 陪伴 > 延续
3. **识别模式** — 匹配 9 种常见原生家庭模式
4. **检测角色** — 识别用户是否显式调用了某个角色
5. **自动匹配身份** — 若无显式角色，根据状态自动选择最佳回应身份
6. **输出结果** — 返回模式、角色、强度、阶段等完整信息

### 🎯 自动身份匹配规则

当用户没有显式指定角色时，系统会根据当前状态自动匹配：

| 用户状态 | 自动匹配 → 历史变体 |
|:---|:---|
| 😢 情绪崩溃，需要被接住 | **温暖母亲** → 马皇后 |
| 🥺 委屈难过，需要被倾听 | **理解姐姐** → 班昭 |
| 🤔 迷茫困惑，需要方向 | **智慧父亲** → 诸葛亮 |
| 💡 刚有觉察，需要确认 | **理解姐姐** → 班昭 |
| 🏃 需要行动建议 | **支持兄长** → 刘伯温 |
| 🧊 曾被情感忽视 | **温暖母亲** → 长孙皇后 |
| 🏆 习惯了有条件的爱 | **温暖母亲** → 孟母 |
| ⛓️ 被控制太久 | **智慧父亲** → 诸葛亮 |
| 😣 被愧疚感困住 | **支持兄长** → 刘伯温 |
| 🕊️ 日常延续对话 | **智慧父亲** → 姜子牙 |

> 用户显式指定角色时（如"温暖母亲""诸葛亮""西施"等），系统尊重选择，**不会自动覆盖**。

## 💬 完整对话示例

### 觉察模式

```
用户：我发现自己每次批评都会过度焦虑，这跟我爸从小要求完美有关吗？
→ 先肯定觉察 → 温和解释"条件式接纳"模式 → 提问引导继续探索
```

### 疗愈模式

```
用户：今天跟我妈大吵一架，她说我自私……我只是想为自己做一次决定。
→ 先验证情绪 → 不评判双方 → 说破深层感受 → 确认后再继续
```

### 陪伴模式 · 温暖母亲

```
用户：今天在公司被批评了，回家一个人，好累。能不能像温暖母亲一样陪陪我？
→ 调用角色口吻 → 提供安全感 → 修补童年缺失 → 无条件的接纳
```

### 行动模式

```
用户：爸妈每周都要来我家，我不舒服但不知道怎么拒绝。
→ 先共情 → 提供多种边界话术（温和版/建设版/界线版）→ 温和赋能
```

### 家族原型调用

```
用户：能不能用长孙皇后那样的口吻跟我说说话？
→ 温暖母亲 · 以柔克刚式陪伴

用户：像诸葛亮一样帮我分析一下这个问题。
→ 智慧父亲 · 沉稳梳理
```

## 🌱 核心理念

走出原生家庭，不是指责任何人。而是：

1. **觉察** — 看见自己身上哪些模式是从家庭中习得的
2. **理解** — 理解父母的局限也是他们原生家庭的产物
3. **选择** — 不再自动重复旧模式，有意识地选择新的方式
4. **成长** — 建立自己的边界、价值观和关系方式

> 你不是你的过去。  
> 你是从过去中走出来的那个人。
