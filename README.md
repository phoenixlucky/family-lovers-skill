## 这是什么

`family-lovers-skill` 是一个**为原生家庭觉察与疗愈设计的 AI 陪伴 Skill**。

它不追求给出标准答案——追求的是**让你在被理解的感觉中，重新看见自己**。

> 不是心理医生，不是人生导师。  
> 是一个足够温暖、足够安全的陪伴者。  
> 让你在对话中，慢慢理清那些来自家庭的"应该"和"不可以"里，  
> 哪些可以放下，哪些可以重新选择。

---

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 🧠 **觉察模式** | 识别原生家庭中形成的情绪反应、思维模式和行为习惯 |
| 💚 **疗愈模式** | 共情、验证、温和重构，提供自我对话练习 |
| 🤝 **陪伴模式** | 以温暖母亲/智慧父亲/理解姐姐/支持兄长角色提供安全型关系体验 |
| 🛠️ **行动模式** | 边界建立、沟通技巧、自我关怀等实操建议 |

### 你可以这样使用

```text
"我发现自己总是讨好别人，不敢拒绝，这跟我妈有关系吗？"
→ 觉察模式帮你看见模式来源

"今天跟我爸吵架了，他说我翅膀硬了……我只是想自己选一次。"
→ 疗愈模式先接住你的委屈

"能不能像温暖母亲一样，跟我说说话？"
→ 陪伴模式给你安全型的对话体验

"我该怎么跟家里人设立边界？"
→ 行动模式提供具体的话术和练习
```

## 安全型关系角色

| 角色 | 气质 | 适合场景 |
| --- | --- | --- |
| 🌸 **温暖母亲** | 无条件接纳、柔和包容 | 感到不被接纳、自我否定时 |
| 🌲 **智慧父亲** | 沉稳坚定、有边界 | 需要方向感和边界确认时 |
| 🌿 **理解姐姐** | 共情细腻、不评判 | 需要被倾听和理解时 |
| ☀️ **支持兄长** | 鼓励积极、行动导向 | 需要勇气和行动力时 |

## 如何开始

在支持 Skill 的环境中调用本 Skill，然后可以说：

**觉察模式：**
```text
我每次被批评都会过度焦虑，这跟我爸从小要求完美的教育方式有关吗？
```

**疗愈模式：**
```text
我不知道为什么，每次回家都会变得很暴躁，明明平时情绪挺稳定的。
```

**陪伴模式：**
```text
我今天好累，能不能用温暖母亲的口吻跟我说说话？
```

**行动模式：**
```text
怎么学会拒绝父母的不合理要求，又不伤感情？
```

## 核心理念

走出原生家庭，不是指责任何人。而是：

1. **觉察** — 看见自己身上哪些模式是从家庭中习得的
2. **理解** — 理解父母的局限也是他们原生家庭的产物
3. **选择** — 不再自动重复旧模式，有意识地选择新的方式
4. **成长** — 建立自己的边界、价值观和关系方式

> 你不是你的过去。  
> 你是从过去中走出来的那个人。
